MVC PHP sem Framework
=====================

### Descrição:

Projeto exemplo, rodando num servidor Apache, utilizando os componentes do Symfony HttpFoundation e Twig.

Assim como poderia utilizar um componente para banco de dados como Doctrine, Eloquent ou o PDO nativo do PHP.

Consume o Web Service SOAP da w3schools https://www.w3schools.com/xml/tempconvert.asmx?WSDL para calculo de conversão de temperatura.
